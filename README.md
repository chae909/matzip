# 🍽️ matzip

> 맛집 정보를 공유하고 관리하는 웹사이트

## 📌 프로젝트 소개

**matzip**은 사용자들이 직접 맛집 정보를 등록하고, 리뷰를 공유하며, 다른 사용자들과 소통할 수 있는 플랫폼입니다.

## 🔧 주요 기능

- **맛집 리스트 관리**
  - 맛집 리스트 생성, 수정, 삭제
  - 댓글 리스트 생성, 수정, 삭제

## 🛠️ 기술 스택

- **Frontend**
  - jsp
  - css

- **Backend**
  - Spring Boot
  - MyBatis
  - MySQL
